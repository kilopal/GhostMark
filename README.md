## What is GhostMark?

Text generated by Large Language Models (like ChatGPT or Claude) contains hidden statistical and cryptographic watermarks (like Google SynthID). GhostMark destroys these watermarks using a massive **1.8 Billion Parameter Neural Network** (Microsoft Phi-3) running *entirely* inside your browser's local GPU. 

Unlike CLI tools or Docker containers that are meant for servers, GhostMark runs as a frictionless Chrome Extension.

- ❌ No API Keys needed.
- ❌ No Docker/CLI required.
- ❌ No tracking or telemetry.
- ✅ Runs 100% locally in your browser.
- ✅ Defeats zero-width character steganography.
- ✅ Defeats complex SynthID statistical watermarks.

---

## 🔥 Features

### Layer 1: Fast WASM Normalization
Uses an ultra-fast local WebAssembly (Rust) engine to instantly strip Unicode trickery, zero-width spaces, and homoglyphs. It executes in roughly ~2ms directly on your CPU.

### Layer 2: Deep Statistical Scrub (WebGPU)
Uses `@mlc-ai/web-llm` and WebGPU to boot up a massive 1.8GB Llama/Phi model directly into your browser's hidden Offscreen Document. It fundamentally rewrites the underlying semantic structure of the text, destroying advanced cryptographic token watermarks (like SynthID) while preserving your exact paragraph lengths and human tone.

## 🚀 Installation

Because this extension uses bleeding-edge WebGPU features, it is not yet on the Chrome Web Store.

1. Clone or download this repository.
2. Go to `chrome://extensions/` in your browser.
3. Enable **Developer mode** in the top right.
4. Click **Load unpacked** and select the `ghostmark/extension` folder.
5. Pin the 👻 icon to your toolbar!

*(Note: The very first time you check "Deep Statistical Scrub", it will download a ~1.8GB model into your browser's IndexedDB. Subsequent runs will be completely instant).*

## 🛠️ Architecture

GhostMark pushes the boundaries of Chrome Extension Manifest V3 limits:

- **Frontend:** Pure Vanilla JS + HTML (Zero bloat).
- **WASM Engine:** Rust compiled to WebAssembly for sub-millisecond string parsing.
- **WebLLM Offscreen Document:** Because MV3 Background Service Workers cannot access the GPU, we dynamically spawn a hidden HTML page (`offscreen.html`) which executes `@mlc-ai/web-llm` with WebGPU hardware acceleration. 

## 🛡️ Privacy First

GhostMark is built on absolute paranoia. It doesn't even have the capability to send your text to the cloud. All Neural Network inference is executed entirely by your local graphics card.
